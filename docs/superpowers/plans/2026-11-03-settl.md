# Settl.ai: Implementation Plan

- **Spec:** [`docs/superpowers/specs/2026-11-03-settl-design.md`](../specs/2026-11-03-settl-design.md)
- **Status:** FINAL v1.0
- **Platform:** responsive web app (Next.js); no native mobile app
- **Team:** solo
- **Window:** Thu Nov 5 (kickoff) to Sun Nov 8, 8:00 AM Manila (submission)
- **Rule:** no product code before kickoff. Day 0 is setup and reading only.

> **Revision 2026-11-04.** The API and MCP design in [`2026-11-04-settl-api-mcp-design.md`](../specs/2026-11-04-settl-api-mcp-design.md) overrides this plan wherever they differ:
> - Settl now hosts the MCP server and holds agent keys.
> - Payment header kinds are now `tx` and `commit`. Pre-signed authorizations (`preSignAuthorize`, `submitPreSigned`) are removed.
> - npm workspaces replace pnpm.
> - Spike S1 is settled: it's a plain `require_auth`. S2 is settled: the cap applies to each payment. S5 is settled: any wallet can fund. S6 is settled: nonces must be strictly greater, gaps allowed.
> - The four automations (webhooks, auto-claim, low-budget alerts, approvals) are in scope.

## 0. Assumptions (defaults for the spec's open questions)

| Spec Q | Default used in this plan | Change cost if you disagree |
|---|---|---|
| Q1 Name | `settl` | Rename only |
| Q2 LLM | AI SDK with the model set in `AGENT_MODEL` env, so any provider you have a key for works | None |
| Q3 Wallets | Custodial testnet keypairs, encrypted at rest (`WALLET_ENC_KEY`) | +1 day for non-custodial |
| Q4 Concurrency | Payments sent one at a time per agent | Low |
| Q5 Hosting | Vercel (web, resibo) and Neon Postgres | Low |

Other decisions:
- **Package manager:** pnpm workspaces
- **Tests:** Vitest
- **DB:** Prisma with Neon Postgres
- **Validation:** Zod
- **Amounts:** `bigint` in stroops (7 decimals) internally, decimal strings on the wire
- **Testnet-only tests** are tagged and run with `pnpm test:testnet`. The default `pnpm test` never touches the network.

## 3. Frozen shared interfaces (write these first on Day 1, change only with a note in this file)

### 3.1 `packages/core/src/protocol.ts`
```ts
export type Mode = "per-call" | "outcome";
export type Amount = string; // decimal string, 7dp max, e.g. "2.0000000"

export interface Criteria {
  schema: string;                       // e.g. "resibo.receipt.v1"
  required?: string[];
  minConfidence?: number;
  lineItemsSumToTotal?: { tolerance: number };
}

export interface Quote {
  settl: "0.1";
  quoteId: string;
  mode: Mode;
  network: "stellar:testnet";
  asset: string;                        // escrow token contract id
  amount: Amount;
  displayPrice: { currency: "PHP"; amount: string };
  merchant: string;                     // G... provider wallet
  escrowContract: string;
  nonce: string;                        // u64 as string
  expiresAt: string;                    // ISO
  resource: string;                     // "POST /parse-receipt"
  description: string;
  criteria?: Criteria;                  // required when mode === "outcome"
  verifier?: string;
}

export type PaymentProof =
  | { quoteId: string; kind: "tx";   txHash: string;       agent: string; deviceHash: string }
  | { quoteId: string; kind: "auth"; authEntryXdr: string; agent: string; deviceHash: string };

export interface Receipt {
  quoteId: string;
  status: "paid" | "not_charged";
  txHash?: string;
  amount: Amount;
  verified: boolean;
  remainingBudget?: Amount;
  reasons?: CheckFailure[];
}

export interface CheckFailure { check: string; message: string }

export interface VerificationResult {
  result: "pass" | "fail" | "error";
  reasons: CheckFailure[];
}

export const HEADER_PAYMENT = "X-PAYMENT";
export const HEADER_RECEIPT = "X-PAYMENT-RECEIPT";
```

### 3.3 `packages/stellar/src/noir.ts`
```ts
export interface TxResult { hash: string; status: "SUCCESS" | "FAILED"; error?: string }
export interface PolicyView { owner: string; agent: string; maxAmount: bigint; asset: string; expiresAt: bigint }

export interface NoirClient {
  // device_registry
  registerDevice(owner: Keypair, deviceHash: string, agent: string): Promise<TxResult>;
  revokeDevice(owner: Keypair, deviceHash: string): Promise<TxResult>;
  // agent_registry
  registerAgent(owner: Keypair, p: { deviceHash: string; agent: string; maxAmount: bigint; asset: string; expiresAt: bigint }): Promise<TxResult>;
  revokeAgent(owner: Keypair, deviceHash: string): Promise<TxResult>;
  getPolicy(deviceHash: string): Promise<PolicyView | null>;
  // payment_escrow
  escrowToken(): Promise<string>;
  fundEscrow(owner: Keypair, deviceHash: string, amount: bigint): Promise<TxResult>;
  authorize(agent: Keypair, a: AuthorizeArgs): Promise<TxResult>;              // per-call
  preSignAuthorize(agent: Keypair, a: AuthorizeArgs): Promise<string>;         // outcome: auth entry XDR
  submitPreSigned(submitter: Keypair, authEntryXdr: string, a: AuthorizeArgs): Promise<TxResult>;
  claim(merchant: Keypair): Promise<TxResult>;
  sweepOnRevoke(owner: Keypair, deviceHash: string, agent: string): Promise<TxResult>;
  balanceOf(deviceHash: string): Promise<bigint>;
  pendingBalance(merchant: string): Promise<bigint>;
  // verification helper
  readAuthorizeTx(txHash: string): Promise<{ ok: boolean; args?: AuthorizeArgs }>;
}

export interface AuthorizeArgs {
  agent: string; deviceHash: string; merchant: string; asset: string; amount: bigint; nonce: bigint;
}
```
All transactions go through `gas.ts` (`sponsorAndSubmit` → `waitForResult`) unless Spike S3 says Soroban sponsorship doesn't work. The fallback is direct submission, with fees paid in testnet XLM.

### 3.4 Settl API (consumed by the SDK; Bearer `SETTL_PROVIDER_KEY`)
| Method & path | Body | Returns |
|---|---|---|
| `POST /api/quotes` | `{ endpointId, agentHint?: { agent, deviceHash } }` | `Quote` |
| `POST /api/payments/verify` | `{ proof: PaymentProof }` (kind `tx`) | `{ ok: boolean; receipt?: Receipt; error?: string }` |
| `POST /api/verify` | `{ proof: PaymentProof /* kind auth */; result: unknown }` | `{ verification: VerificationResult; receipt: Receipt }` |

### 3.5 SDK and client public API
```ts
// settl-sdk
export function settl(opts: { endpointId: string; apiUrl?: string; apiKey?: string }): RequestHandler; // Express

// settl-client
export async function settlFetch(url: string, init: RequestInit & {
  agent: Keypair; deviceHash: string;
  policy: { maxPrice: Amount; allowMerchants: string[] };
  onEvent?: (e: ClientEvent) => void;    // for the agent's reasoning log
}): Promise<{ response: Response; receipt?: Receipt }>;
```
